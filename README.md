# 🌟 ระบบจองห้อง 7 ดาว ซ้อม CLINIC OSPE (Day-by-Day View)
**คณะเภสัชศาสตร์ จุฬาลงกรณ์มหาวิทยาลัย**

ระบบสำรองเวลาฝึกซ้อมห้อง 7 ดาว (CLINIC OSPE) โฉมใหม่ แบบแสดงผลรายวัน (Day-by-Day Responsive View) พร้อมระบบยืนยันตัวตนอัตโนมัติ ตรวจสอบโควตา และเชื่อมต่อ Google Sheets ผ่าน REST API

---

## ✨ ไฮไลท์การปรับปรุงใหม่ (Day-by-Day Redesign)
1. **แสดงผลแบบวันต่อวัน (Day-by-Day)**: ตัดปัญหาตาราง 7 วันที่เบียดเสียดในจอมือถือ โหลดเร็ว ลื่นไหล ไม่ค้าง
2. **เลือกจองได้ทั้งแบบแยกห้อง หรือทั้งห้องพร้อมกัน**:
   - 🚪 **ห้องนอก**: โต๊ะกลมด้านนอก (ความจุ 5 คน)
   - 🛏️ **ห้องใน**: โต๊ะในห้อง (ความจุ 7 คน)
   - 💡 **แตะที่ช่วงเวลา (แถบซ้าย)**: เพื่อเลือกทั้งสองห้องพร้อมกันสำหรับกลุ่มใหญ่หรือการสอบ Mock Exam
3. **แถบสถานะชัดเจน (Status System)**:
   - 🟢 **ว่าง**: แตะเลือกเพื่อสำรองเวลาได้ทันที
   - 🟠 **รอยืนยัน (5 นาที)**: มีตัวนับถอยหลังแบบเรียลไทม์ แตะเพื่อยืนยันตัวตน (Check-in) หรือขอยกเลิก
   - 🔴 **จองแล้ว**: แสดงข้อมูลการจอง
   - 🔵 **ที่เลือก**: แสดงสถานะที่ผู้ใช้กำลังเลือกอยู่
4. **โควตาส่วนตัว 2 ชม./คน/วัน**: ตรวจสอบกับฐานข้อมูลรายชื่อคณะ (StudentData) โดยอัตโนมัติ
5. **ระบบความปลอดภัย PIN 4 หลัก**: ใช้ PIN ในการยกเลิก ป้องกันผู้อื่นแอบกดยกเลิกสิทธิ์
6. **ระบบจองส่วนกลาง / Mock Exam**: สำหรับประธานและฝ่ายวิชาการในการจัดสอบจำลองหลายชั่วโมงต่อเนื่อง

## 💻 การทดสอบและเปิดใช้งานในเครื่อง (Local Testing)
สามารถเปิดไฟล์ `index.html` หรือ `test_local_booking.html` ด้วยเบราว์เซอร์ (Chrome / Edge / Safari) ได้ทันที โดยระบบมี Built-in Mock Data Fallback ในตัว ทำให้ทดสอบได้ทันทีแม้ไม่ได้เชื่อมต่อเน็ต

---

## 🌐 การเปิดใช้งานผ่าน GitHub Pages
1. ไปที่แท็บ **Settings** ของ Repository นี้
2. เลือกเมนู **Pages** ทางด้านซ้าย
3. ในส่วน **Build and deployment > Branch** ให้เลือก Branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. ระบบจะสร้างลิงก์สำหรับเข้าใช้งานผ่าน GitHub Pages ให้ทันที
